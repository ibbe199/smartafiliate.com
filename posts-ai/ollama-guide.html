🧠 ما هو Ollama؟

Ollama هو أداة مجانية ومفتوحة المصدر تتيح لك تشغيل نماذج اللغة الكبيرة (LLMs) محلياً على جهازك بسهولة شديدة. قبل Ollama، كان تشغيل نموذج مثل Llama 3 يتطلب خبرة تقنية عالية. مع Ollama، الأمر بسيط مثل كتابة أمر واحد في الطرفية.

Ollama متوفر على Windows و Mac و Linux، ويدعم أشهر النماذج مفتوحة المصدر: Llama 3، Mistral، Falcon، Gemma، Phi-3، وغيرها.

📌 معلومة مهمة: Ollama مجاني بالكامل ولا يحتوي على أي قيود أو حدود استخدام. كل شيء يعمل محلياً على جهازك.

📥 تثبيت Ollama

Windows:

# اذهب إلى https://ollama.ai/download
# حمّل ملف OllamaSetup.exe
# شغّله واتبع التعليمات (التالي → التالي → إنهاء)

Mac:

# تحميل Ollama-darwin.dmg من الموقع
# اسحب Ollama إلى مجلد Applications
# افتح التطبيق

Linux:

curl -fsSL https://ollama.ai/install.sh | sh

⚙️ الأوامر الأساسية

تشغيل نموذج:

ollama run llama3

قائمة النماذج المحملة:

ollama list

تحميل نموذج بدون تشغيل:

ollama pull mistral

حذف نموذج:

ollama rm falcon

عرض معلومات النموذج:

ollama show llama3

📦 النماذج المتاحة

Ollama يدعم العشرات من النماذج. إليك أشهرها:

  • llama3 (8B, 70B): من Meta – أفضل أداء عام.
  • mistral (7B): من Mistral AI – صغير وسريع.
  • mixtral (8x7B): إصدار الخبراء – أداء قريب من GPT-3.5.
  • falcon (7B, 40B): من TII الإمارات – دعم ممتاز للعربية.
  • gemma (2B, 7B): من Google – صغير جداً.
  • phi3 (3.8B): من Microsoft – صغير جداً، أداء جيد.
  • codellama (7B, 34B, 70B): متخصص في البرمجة.
  • llama2 (7B, 13B, 70B): الإصدار السابق.

🛠️ إنشاء نماذج مخصصة (Modelfiles)

يمكنك إنشاء نموذج مخصص بإعداداتك الخاصة (مثل نظام التعليمات). أنشئ ملف `Modelfile` بالمحتوى:

FROM llama3

# تعيين نظام التعليمات (System Prompt)
SYSTEM أنت مساعد عربي متخصص في التسويق بالعمولة. أجب باختصار ووضوح.

# تعيين إعدادات الحرارة (الإبداع)
PARAMETER temperature 0.7
PARAMETER top_p 0.9

# تعيين قالب المحادثة
TEMPLATE """{{ if .System }}<|start_header_id|>system<|end_header_id|>

{{ .System }}<|eot_id|>{{ end }}{{ if .Prompt }}<|start_header_id|>user<|end_header_id|>

{{ .Prompt }}<|eot_id|>{{ end }}<|start_header_id|>assistant<|end_header_id|>

{{ .Response }}<|eot_id|>"""

ثم أنشئ النموذج:

ollama create my-affiliate-assistant -f ./Modelfile
ollama run my-affiliate-assistant

🔌 استخدام Ollama كـ API

Ollama يشغل خادم API تلقائياً على المنفذ 11434. يمكنك استخدامه من أي تطبيق:

# توليد نص (Generate)
curl http://localhost:11434/api/generate -d '{
  "model": "llama3",
  "prompt": "مرحباً، كيف حالك؟"
}'

# محادثة (Chat)
curl http://localhost:11434/api/chat -d '{
  "model": "llama3",
  "messages": [
    {"role": "user", "content": "ما هو التسويق بالعمولة؟"}
  ]
}'

🖥️ واجهات مستخدم رسومية لـ Ollama

إذا كنت لا تفضل سطر الأوامر، هناك واجهات رسومية تعمل مع Ollama:

  • Open WebUI (أفضل خيار): واجهة ويب جميلة تشبه ChatGPT. تثبيت سهل باستخدام Docker.
  • Ollama Web UI: واجهة بسيطة وخفيفة.
  • Continue (لـ VS Code): مكمل ذكاء اصطناعي للمبرمجين.
  • Enchanted (لـ Mac): تطبيق سطح مكتب أنيق.

💡 نصائح وحيل متقدمة

  • تغيير عدد الخيوط (Threads): لزيادة السرعة، استخدم --num-thread. مثال: ollama run llama3 --num-thread 8
  • تغيير حجم السياق (Context Size): لزيادة طول المحادثة، استخدم --ctx-size. مثال: ollama run llama3 --ctx-size 8192
  • حفظ المحادثة: استخدم إعادة التوجيه لحفظ الردود: ollama run llama3 > conversation.txt
  • تشغيل Ollama كخدمة: على Linux، يمكنك تشغيله في الخلفية باستخدام systemctl.

✅ الإيجابيات / ❌ السلبيات

✅ الإيجابيات:

  • مجاني بالكامل
  • سهل الاستخدام (أمر واحد لتشغيل النماذج)
  • يدعم أشهر النماذج مفتوحة المصدر
  • يعمل على Windows و Mac و Linux
  • يقدم API للتكامل مع التطبيقات

❌ السلبيات:

  • النماذج الكبيرة تحتاج أجهزة قوية
  • لا يدعم التعديل (Fine-tuning) مباشرة
  • بعض النماذج غير متوفرة (مثل GPT-4)

🎯 الخلاصة

Ollama هو أسهل وأسرع طريقة لتشغيل نماذج الذكاء الاصطناعي محلياً على جهازك. إذا كنت تريد تجربة Llama 3 أو Mistral أو Falcon دون تعقيدات، ابدأ بـ Ollama.

نصيحتي: ابدأ بتشغيل Llama 3 8B. إنه نموذج قوي ويعمل على معظم أجهزة الكمبيوتر الحديثة. إذا أعجبتك التجربة، جرّب نماذج أخرى.
