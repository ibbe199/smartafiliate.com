# smartafiliate.com

موقع عربي عملي يهتم بالذكاء الاصطناعي، أدوات AI، التسويق بالعمولة، السيو، تعلم AI، والأدوات مفتوحة المصدر.

الرابط الرسمي:

```text
https://www.smartafiliate.com/
```

خريطة الموقع لمحركات البحث:

```text
https://www.smartafiliate.com/sitemap.xml
```

خريطة الموقع للزوار:

```text
https://www.smartafiliate.com/sitemap.html
```

---

## الملفات التنظيمية المهمة

```text
site.js
header-fix.css
all-articles.js
link-enhancer.js
monetization-manager.js
footer-manager.js
sitemap.xml
sitemap.html
```

وظيفة الملفات:

- `site.js`: بناء الهيدر، تحميل السكربتات العامة، وتحسين الصور والموبايل.
- `header-fix.css`: إصلاح الهيدر والموبايل والقائمة والتجاوب.
- `all-articles.js`: تجميع المقالات وعرضها في صفحات المقالات.
- `link-enhancer.js`: ربط المقالات ببعضها وإضافة روابط داخلية وخارجية.
- `monetization-manager.js`: Google Tag Manager وروابط الأفلييت وتتبع الضغطات.
- `footer-manager.js`: بناء فوتر موحد ومنظم لكل صفحات الموقع.
- `sitemap.xml`: خريطة الموقع لمحركات البحث.
- `sitemap.html`: خريطة موقع مرئية للزوار.

## SEO والفهرسة

تم تجهيز الموقع لدعم الفهرسة عبر:

- روابط داخلية بين المقالات.
- صفحة `sitemap.html` للزوار.
- ملف `sitemap.xml` لمحركات البحث.
- صفحات سياسة الخصوصية والشروط والإفصاح.
- صور OG/Twitter في الصفحات المهمة.
- روابط خارجية آمنة باستخدام `nofollow` و `noopener` عند الحاجة.

## ملاحظات تطوير

عند إضافة مقال جديد:

1. أضف ملف المقال داخل `posts-ai/` أو `articles/`.
2. أضف رابطه داخل `all-articles.js` حتى يظهر في صفحات المقالات.
3. أضفه إلى `sitemap.xml`.
4. استخدم صورة مناسبة من `assets/images/` أو أنشئ صورة جديدة.
5. تأكد من وجود عنوان، وصف، canonical، وبيانات OG.
